# LPIPS Video Evaluation

This workspace includes a standalone LPIPS evaluation path for comparing a
reference video against videos generated by a world model. A common setup is to
use Unity-rendered videos as the reference side and model outputs as the world
model side.

## Layout

- `metrics/video_io.py`: shared video metadata and timestamp-aligned sampling
- `metrics/lpips_vgg.py`: LPIPS with the VGG backbone for generic video pairs
- `tools/evaluate_world_model_lpips.py`: batch runner over a JSONL manifest
- `scripts/evaluate_world_model_lpips.sh`: runnable command template

## Dependencies

Install the minimal dependencies needed for LPIPS evaluation:

```bash
pip install numpy opencv-python torch torchvision lpips
```

## Manifest format

Use JSONL with one video pair per line. Required keys:

- `sample_id`
- `reference_video`
- `world_model_video`

Optional keys:

- `world_model_name`
- `run_id`
- `prompt`

The runner also accepts legacy aliases such as `unity_video`, `gt_video`,
`candidate_video`, `genie3_video`, and `pred_video`, but the generic names
above are preferred for new manifests.

Example:

```json
{"sample_id":"ball_roll_001","world_model_name":"genie3","run_id":"seed0","prompt":"A ball rolls down a ramp","reference_video":"/data/unity/ball_roll_001.mp4","world_model_video":"/data/genie3/ball_roll_001_seed0.mp4"}
{"sample_id":"ball_roll_001","world_model_name":"genie3","run_id":"seed1","prompt":"A ball rolls down a ramp","reference_video":"/data/unity/ball_roll_001.mp4","world_model_video":"/data/genie3/ball_roll_001_seed1.mp4"}
{"sample_id":"ball_roll_001","world_model_name":"other_wm","run_id":"seed0","prompt":"A ball rolls down a ramp","reference_video":"/data/unity/ball_roll_001.mp4","world_model_video":"/data/other_wm/ball_roll_001_seed0.mp4"}
```

## Usage

```bash
python tools/evaluate_world_model_lpips.py \
  --manifest_jsonl /path/to/world_model_lpips_manifest.jsonl \
  --output_jsonl reports/world_model_lpips/results.jsonl \
  --summary_csv reports/world_model_lpips/summary.csv \
  --eval_fps 4 \
  --max_pairs 32
```

The runner aligns videos by shared duration and samples matching timestamps
before computing LPIPS for each frame pair. Lower LPIPS means the world-model
video is perceptually closer to the reference video.
